本项目灵感来源于 [Xekr 的专栏](https://www.bilibili.com/opus/565791108653279073) 中的懒人合成数据包，但原数据包不能满足个人的需求，故自行编写了本项目。
目前本项目仅适用于 JE 1.21.5 版本。

## 项目简介

- 与原版等价但更简便/合成步骤更少的配方
- 钓鱼时有概率钓上鞘翅、海绵、海洋之心 ~~相信你也不希望为了这些东西跑图把存档搞得大大的~~
- 使用带有精准采集的镐挖掘紫水晶母岩能够使紫水晶母岩掉落
